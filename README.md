# # Currency Converter

Welcome to the Currency Converter! This application helps users convert amounts between different currencies (USD to INR, EUR, GBP, AUD, JPY) in a simple, user-friendly interface.

---

## Features:
- Easy-to-use graphical user interface.
- Conversion between multiple currencies.
- Input validation and error handling.
- Simple and efficient conversion logic.

---

## Technologies Used:
- **JavaFX**: For building the user interface.
- **Java**: Core backend logic.
