# Currency Converter

Welcome to the **Currency Converter** project! This simple application helps users convert US dollars (USD) into various popular currencies with just a few clicks. It's an easy-to-use, console-based tool that makes currency conversion accessible and efficient.

---

## Features:
- Convert USD to different currencies: INR, EUR, GBP, AUD, JPY.
- Input validation to ensure correct user input.
- Clear and simple user interface via console.
- Fast and efficient conversion with static exchange rates.
  
---

## Supported Currencies:
- **USD to INR (Indian Rupee)**
- **USD to EUR (Euro)**
- **USD to GBP (British Pound)**
- **USD to AUD (Australian Dollar)**
- **USD to JPY (Japanese Yen)**
